# README_ZH

HSV颜色阈值调整工具使用步骤

第一步：打开下图位置中的HSV.exe文件

![image-20240912104303288](.\img\path.png)



第二步：点击选择图像，选择需要导入的图像文件（导入的图像需要存放在img文件夹内）

![image-20240912104634255](.\img\image.png)

第三步：拉动滑动条，对图像进行HSV阈值分割，调整到合适的HSV阈值范围，可参考下面的颜色范围表格进行调整

![image-20240912110206091](.\img\table.png)

![adjust](.\img\adjust.png)

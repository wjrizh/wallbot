- ## 颜色识别IIC寄存器说明（设备地址：0x52）



### 颜色识别（图像分辨率：240x240）

| 寄存器 | 数据格式（unsigned char）                                    |
| ------ | ------------------------------------------------------------ |
| 0x00   | data[0]:红色中心X轴坐标<br/>data[1]:红色中心Y轴坐标<br/>data[2]:红色检测框宽度<br/>data[3]:红色检测框长度 |
| 0x01   | data[0]:绿色中心X轴坐标<br/>data[1]:绿色中心Y轴坐标<br/>data[2]:绿色检测框宽度<br/>data[3]:绿色检测框长度 |
| 0x02   | data[0]:蓝色中心X轴坐标<br/>data[1]:蓝色中心Y轴坐标<br/>data[2]:蓝色检测框宽度<br/>data[3]:蓝色检测框长度 |
| 0x03   | data[0]:紫色中心X轴坐标<br/>data[1]:紫色中心Y轴坐标<br/>data[2]:紫色检测框宽度<br/>data[3]:紫色检测框长度 |
| 0x04   | data[0]:红色id号<br/>data[1]:绿色id号<br/>data[2]:蓝色id号<br/>data[3]:紫色id号 |

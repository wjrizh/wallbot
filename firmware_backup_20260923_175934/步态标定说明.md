# 尺蠖机器人 步态几何标定说明

换新机器（电机安装角变化）时，只改本文件所述参数与常量，无需重写算法。

## 一、机构模型

单侧腿链（前后对称）：

```
              M2 (顶点, 两臂交点)
             /  \
        L1  /    \  L2          L1 = L2 = KIN_ARM_LEN
           /      \
        M1          M3          M1=前髋, M3=后髋
         |           |
        前足         后足        脚杆垂直地面, 长 KIN_LEG_LEN
```

- M1: 前腿关节(前髋); M2: 中间关节(膝); M3: 后腿关节(后髋)
- L1(M1-M2) = L2(M2-M3), 两臂等长, 向上呈 ^ 形 (M2 在两髋连线上方)
- 脚杆始终垂直于地面, 脚底在 M1/M3 正下方
- 站立: 两臂各与地面成 KIN_STAND_THETA 角, 两髋等高

## 二、角度定义与映射

- th1 = L1 与水平地面夹角(向上为正) = (M1 - KIN_ZERO_M1) / KIN_RATIO_M1
- th2 = L2 与水平地面夹角(向上为正) = (M3 - KIN_ZERO_M3) / KIN_RATIO_M3
- phi = 两臂在 M2 处内角(钝角) = 180 - (M2 - KIN_ZERO_M2) * KIN_RATIO_M2

反解(舵机角)：

- M1 = KIN_RATIO_M1 * th1 + KIN_ZERO_M1
- M3 = KIN_RATIO_M3 * th2 + KIN_ZERO_M3
- M2 = KIN_ZERO_M2 + (180 - phi) / KIN_RATIO_M2

几何关系：

- 两髋(两足)水平距 X = L*cos(th1) + L*cos(th2)
- 顶角 phi = 180 - th1 - th2 (两臂向上, M2 在上)

## 三、标定参数 (config.h)

| 宏 | 含义 | 当前值 |
|---|---|---|
| KIN_ARM_LEN     | 臂长 L1=L2 (mm) | 220.0 |
| KIN_LEG_LEN     | 垂直脚杆长 (mm) | 135.0 |
| KIN_RATIO_M1    | M1 传动比(舵机:几何角) | 2.0 |
| KIN_RATIO_M3    | M3 传动比 | 2.0 |
| KIN_RATIO_M2    | M2 传动比 | 1.0 |
| KIN_ZERO_M1     | th1=0(臂水平)时 M1 舵机读数 | 10.0 |
| KIN_ZERO_M3     | th2=0 时 M3 舵机读数 | -5.0 |
| KIN_ZERO_M2     | 两臂共线(phi=180)时 M2 舵机读数 | 70.0 |
| KIN_STAND_THETA | 站立臂角 (度) | 20.0 |
| GAIT_STEP_SPEED | 步态运动时长(秒), 越大越慢 | 4.0 |

### 三个零位读数如何测

1. KIN_ZERO_M1: 让 L1 与地面平行(th1=0), 读 M1 舵机值。
2. KIN_ZERO_M3: 让 L2 与地面平行(th2=0), 读 M3 舵机值。
3. KIN_ZERO_M2: 让两臂拉直成一条线(phi=180, 两足最远), 读 M2 舵机值。

### 站立姿态校验

站立时两臂对称 th1=th2=KIN_STAND_THETA, 两髋等高：

- 站立两足距 = 2*KIN_ARM_LEN*cos(KIN_STAND_THETA) = 2*220*cos20 = 413.5 mm
- M1 = 2*20+10 = 50; M3 = 2*20-5 = 35; M2 = 70+2*20 = 110

即站立舵机角应为 (M1,M2,M3) = (50,110,35)。若实测不同, 检查零位/传动比/站立角。

## 四、步距求解 (Kinematics_SolveStep)

输入步距 step(mm)(收缩时两足水平距缩小量), 输出后腿落地终点舵机角：

```
X  = 站立两足距 - step          = 2*L*cos(th_stand) - step
th = arccos( X / (2*L) )        对称等高, th1=th2
M1 = 2*th + 10
M3 = 2*th - 5
M2 = 70 + 2*th
```

例(站立距 413.5)：

| step | X | th | M1 | M2 | M3 |
|---|---|---|---|---|---|
| 50  | 363.5 | 34.3 | 78.6  | 138.6 | 63.6 |
| 80  | 333.5 | 40.7 | 91.4  | 151.4 | 76.4 |
| 100 | 313.5 | 44.6 | 99.2  | 159.2 | 84.2 |

注意: step 越大 M2 越接近 180(机械极限)。建议 step <= 100。

## 五、迈步流程 (Gait_WalkSequence)

尺蠖式, 一次迈步含两段：

段1 后腿靠拢(前腿吸附)：
1. 后泵松开(前泵吸)
2. 后腿抬到抬升中间态(角度手动标定)
3. 后腿放下到 远伸过渡(终点 M2-10) -> 再 落地(终点 SolveStep(step))

段2 前腿回位(后腿吸附)：
1. 前泵松开(后泵吸)
2. 前腿抬到抬升中间态
3. 前腿放下到 远伸过渡(50,100,35) -> 再 复位(50,110,35)(回站立)

远伸过渡: 尺蠖放下时腿可能翘, 先让 M2 少 10 度(腿伸远), 再收缩到目标(M2 到位)吸附稳定。

## 六、抬升中间态 (手动标定)

抬起过程中间姿态角度, 需按机械实测填写 (gait_engine.cpp)：

- 后腿抬升中间态: M1=124.0, M2=130.4, M3=35.0  (当前值, 可调)
- 前腿抬升中间态: M1=50.0, M2=130.0, M3=109.0  (当前值, 可调)

标定方法: 手动把该腿抬到期望高度+收缩量, 记录三个舵机角, 填入对应 Servo_Set 调用。

## 七、换新机器操作步骤

1. 测三个零位读数: KIN_ZERO_M1 / M3 / M2 (见第三节)。
2. 测三个传动比: KIN_RATIO_M1 / M3 / M2。
3. 测臂长 KIN_ARM_LEN、脚杆 KIN_LEG_LEN、站立角 KIN_STAND_THETA。
4. 填入 config.h。
5. 校验站立角输出是否等于实测站立 (M1,M2,M3)。
6. 手动标定两处抬升中间态角度, 填入 gait_engine.cpp。
7. 编译烧录测试。

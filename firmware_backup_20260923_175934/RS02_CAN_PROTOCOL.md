# RS02 电机 CAN 通信协议完整文档

> 来源：Windows 上位机 motor_tool.exe（motorstudio 0.0.14L）反汇编 + 官方 SDK/ROS 示例 + 实测验证

## 1. 物理链路与 AT 指令

上位机通过 USB-CAN(AT 指令模块) 转接串口通信。初始化序列（函数 0x422780，switch case 0..6）：

| case | AT 指令 | 说明 |
|------|---------|------|
| 0 | AT+AT | 测试 |
| 1 | AT+CAN_MODE=0 | 正常模式 |
| 2 | AT+CAN_FRAMEFORMAT=1,0,1,0 | 帧格式 |
| 3 | AT+CAN_BAUD=1000000 | 波特率 1Mbps |
| 4 | AT+CAN_FILTER0=1,0,0,0 | 全接收 |
| 5 | AT+USART_PARAM=<...>,0,0,0 | 串口参数 |
| 6 | AT+CG | 开始 |

每条以 \r\n 结尾。

### 1.1 CAN 帧 → 串口包封装（函数 0x422eb0）

    "AT" | can_id[4字节大端] | dlc[1字节] | data[dlc] | \r\n

## 2. 29 位扩展帧 ID 构造

    can_id = (type << 24) | (extra_data << 8) | motor_id

其中 bit8-15 固定为 HOST_ID = 0xFD（反汇编 38 处 or ah,0xfd）。

| 位段 | 含义 |
|------|------|
| bit28-24 | 通信类型 type (0~31) |
| bit23-16 | extra_data（新ID、torque、波特率等） |
| bit15-8 | HOST_ID = 0xFD |
| bit7-0 | 目标 motor_id |

发送帧与应答帧布局不同，见第 4 节。

## 4. 应答帧 / 反馈帧布局

### 4.1 类型 0（GetID）应答

实测：电机原 ID=0x7F 时

    ID   = 0x00007FFE   (motor_id 在 bit8-15，bit7-0 = 0xFE)
    data = 5E 07 30 21 10 70 30 17

改 ID 为 0x01 后：

    ID = 0x000001FE

要点：应答帧中 motor_id 落在 bit8-15，bit7-0 固定 0xFE，与发送帧布局不同。

### 4.2 类型 2（状态反馈）

电机主动上报，实测：

    ID   = 0x02807FFD   (type=2, bit15-8=0x80, bit7-0=0xFD 回显主机ID)
    data = 96 E1 80 39 80 0A 01 22

data 大端解析：位置u16, 速度u16, 扭矩i16, 温度u16。

### 4.3 官方接收过滤规则（ROS 示例）

    rfilter.can_id   = (motor_id << 8) | CAN_EFF_FLAG;
    rfilter.can_mask = (0xFF << 8) | CAN_EFF_FLAG;

即按 bit8-15 匹配电机 ID。反馈帧 mid(bit15-8)=电机ID，eid(bit7-0)=0xFD(主机ID)。

## 5. 运控帧（type 1）编码

### 5.1 ID 构造

    can_id = (1 << 24) | (torque_u16 << 8) | (0xFD << 8) | motor_id

即 (1<<24) | (torque_u16<<8) | 0xFD00 | motor_id，torque 占 bit16-23。

### 5.2 data 布局（8 字节，大端）

| 字节 | 内容 | 量程（RS02） |
|------|------|--------------|
| data[0..1] | 目标位置 u16 | ±4π (12.566 rad) |
| data[2..3] | 目标速度 u16 | ±44 rad/s |
| data[4..5] | Kp u16 | 0~500 |
| data[6..7] | Kd u16 | 0~5 |

### 5.3 归一化公式（反汇编 0x423f65）

    位置u16 = (pos / 4π + 1) * 65535/2
    速度u16 = (vel / 44 + 1) * 65535/2
    Kp u16  = Kp / 500 * 65535
    Kd u16  = Kd / 5   * 65535

浮点常量（真实 VA）：

| 地址 | 值 | 含义 |
|------|-----|------|
| 0x4f9170 | 12.57 | 4π（位置满量程） |
| 0x4f9174 | 65535.0 | 16 位归一化 |
| 0x4f9178 | 25.14 | 8π（双倍范围/扭矩） |
| 0x4f917c | 10.0 | 缩放因子 |
| 0x4f9180 | 1.0 | 单位缩放 |

## 6. 写参数帧（type 0x12）

### 6.1 data 布局

    data[0..1] = Index  (小端)
    data[2..3] = 0x0000
    data[4..7] = value  (小端，float 或 int)

### 6.2 参数索引（官方手册 4.1.11 可读写单个参数表）

| Index | 名称 | 描述 | 类型 | 单位 |
|-------|------|------|------|------|
| 0x7005 | run_mode | 0运控/1位置PP/2速度/3电流/5位置CSP | uint8 | |
| 0x7006 | iq_ref | 电流模式 iq 指令 | float | A |
| 0x700A | spd_ref | 转速模式转速指令 | float | rad/s |
| 0x700B | limit_torque | 转矩限制 | float | Nm |
| 0x7010 | cur_kp | 电流环 Kp | float | 默认0.17 |
| 0x7011 | cur_ki | 电流环 Ki | float | 默认0.012 |
| 0x7014 | cur_filt_gain | 电流滤波系数 | float | 默认0.1 |
| 0x7016 | loc_ref | 位置模式角度指令 | float | rad |
| 0x7017 | limit_spd | 位置模式速度限制 | float | rad/s |
| 0x7018 | limit_cur | 速度/位置模式电流限制 | float | A |
| 0x7019 | mechPos | 负载端计圈机械角度 | float | rad |
| 0x701A | iqf | iq 滤波值 | float | A |
| 0x701B | mechVel | 负载端转速 | float | rad/s |
| 0x701C | VBUS | 母线电压 | float | V |
| 0x701E | loc_kp | 位置环 Kp | float | 默认40 |
| 0x701F | spd_kp | 速度环 Kp | float | 默认6 |
| 0x7020 | spd_ki | 速度环 Ki | float | 默认0.02 |

上位机反汇编中另出现 0x7001/0x7002/0x7003/0x7007/0x7012/0x7022/0x7024(vel_max)/0x7025(acc_set)/0x710d/0x731d/0x7f8c，其中 vel_max/acc_set 用于 PP 模式（0x40e0c2）。

### 6.3 run_mode 取值（官方手册 4.1.11）

| 值 | 模式 |
|----|------|
| 0 | 运控模式 (Motion) |
| 1 | 位置模式 (PP) |
| 2 | 速度模式 |
| 3 | 电流模式 |
| 5 | 位置模式 (CSP) |

注：官方手册明确无枚举 4。上位机写 0x7005 时出现 ecx=0x7 与 ecx=0x107 两种（0x40cce5/0x40cd99/0x40ce59），
且分别在不同独立函数中发送，对应不同 UI 模式按钮；0x107 低字节=0x07。
这说明上位机使用的是固件私有 mode 编码，与手册公开枚举不一致，待实测确认。

## 7. 改 CAN ID 流程（type 7）

### 7.1 帧构造

    can_id = (7 << 24) | (new_id << 16) | (0xFD << 8) | old_id
    data   = 8 字节（通常全 0）

反汇编（0x423d00）：
    movzx eax, BYTE PTR [rbx+0x5794]   ; new_id
    shl   eax, 0x10                     ; 放到 bit16
    or    ah, 0xfd                      ; host=0xFD
    or    eax, 0x7                      ; type=7

### 7.2 实测验证

| 步骤 | 帧 ID | 结果 |
|------|-------|------|
| 探测旧 ID 0x7F | 0x00007FFD | 有应答 0x00007FFE |
| 发改 ID 帧 | 0x0701FD7F | — |
| 探测新 ID 0x01 | 0x000001FD | 有应答 0x000001FE |
| 探测旧 ID 0x7F | — | 无应答 |

改 ID 后需执行 type 24（保存参数）才能掉电不丢失。

## 8. 设机械零位（type 6）

    can_id = (6 << 24) | (0xFD << 8) | motor_id
    data[0] = 1 字节参数（来自 0x58c8）
    发送后延时 100ms

## 9. 波特率修改（type 0x16=22，官方手册）

    can_id = (0x16 << 24) | (0xFD << 8) | motor_id
    data[0]: 01=1M 02=500K 03=250K 04=100K

官方手册定义类型 22 为波特率修改。上位机界面有 1Mbps/500kbps/250kbps/125kbps 选项（字符串 0x4f6393..0x4f63a9）。
注：上位机反汇编中未找到独立的 type22 帧构造（grep or eax,0x16 无载体），待实测确认。

## 10. 数据保存（type 0x18=24）

    can_id = (0x18 << 24) | (0xFD << 8) | motor_id

data 视 cl（参数 id/命令类型）而定（函数 0x40de10）：

- cl <= 0x1F：data = 01 00 00 00 00 00 00 00
- cl > 0x1F：data = 01 02 03 04 05 06 01 00
- cl == 2：改用 type=0x17(23)（主动上报开关），见 0x40e010/0x40e020

## 12. 上位机状态机（0x5a84）

状态存于 [rbx+0x5a84]，跳转表 0x4f81ec，共 31 个状态（0~0x1e）。各状态对应不同超时（20ms/50ms/100ms）与动作序列：使能→等待→运控、参数写入序列、改ID序列、保存参数。

结构偏移（基址 rbx）：

| 偏移 | 含义 |
|------|------|
| 0x5718 | 参数数组 |
| 0x5730/0x5734 | 发送 ID 的 extra 字段 |
| 0x5738 | 命令索引 |
| 0x573c | 波特率编码 |
| 0x5744 | 标志位 |
| 0x5750 | 子状态 |
| 0x5770 | 数据缓冲指针 |
| 0x5778 | 数据长度 |
| 0x5790 | motor_id |
| 0x5794 | 新 ID（改 ID 用） |
| 0x57a0 | 8 字节数据数组 |
| 0x581f | 数组索引 |
| 0x5840 | 设备索引表 |
| 0x58c8 | 设零参数 |
| 0x5a84 | 状态机状态 |
| 0x5a8c | 超时计数器 |
| 0x5a94 | 重试计数 |

## 14. 典型操作序列

### 14.1 获取 ID
    TX: (0<<24)|(0xFD<<8)|motor, data=8x00
    RX: ID=0x0000(motor)FE, data=5E 07 30 21 10 70 30 17

### 14.2 使能
    TX: (3<<24)|(0xFD<<8)|motor, data=8x00

### 14.3 运控（位置模式）
    1. 写 run_mode: type18, Index=0x7005, value=0
    2. 写 limit_spd: type18, Index=0x7017, value=速度限制
    3. 循环发 type1: data=位置u16|速度u16|Kp u16|Kd u16（20ms 周期）

### 14.4 停止
    TX: (4<<24)|(0xFD<<8)|motor, data[0]=clear_error

### 14.5 改 ID + 保存
    TX: (7<<24)|(new_id<<16)|(0xFD<<8)|old_id, data=8x00
    TX: (0x18<<24)|(0xFD<<8)|new_id, data[0]=1

## 15. 官方手册对照（product_manual_robStride02）

| 项目 | 上位机反汇编 | 官方手册 | 结论 |
|------|------|------|------|
| HOST_ID | 0xFD | 0xFF | 不同,两者电机均响应 |
| type22 | 未找到构造 | 波特率修改 | 手册定义 |
| type23 | 主动上报开关 | 主动上报开关 | 一致 |
| type24 | 数据保存 | 数据保存 | 一致 |
| run_mode | 0x7/0x107(私有) | 0/1/2/3/5 | 不一致,待实测 |
| type1 torque | ID bit16-23 | 手册表格写 Byte2 | 固件实际放ID,手册笔误 |
| type17 | UI未调用 | 已定义 | 协议存在 |
| type21 | 未见 | 故障反馈 | 手册定义 |

官方手册未定义 type 8/9/10/11/13/14/19/26，属上位机私有。

手册给出的控制模式写入序列：

- 运控: 上电默认 -> type3使能 -> type1运控
- 电流: type18写run_mode=3 -> type3使能 -> type18写iq_ref
- 速度: type18写run_mode=2 -> type3使能 -> type18写limit_cur -> type18写spd_ref
- 位置CSP: type18写run_mode=5 -> type3使能 -> type18写limit_spd -> type18写loc_ref
- 位置PP: type18写run_mode=1 -> type3使能 -> type18写vel_max -> type18写acc_set -> type18写loc_ref

停止: type4
